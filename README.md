# Fire Alarm System using Arduino UNO

## Components Used
- Arduino UNO
- LM35 Temperature Sensor
- MQ Gas Sensor
- LED
- Buzzer

## Description
This project detects high temperature and gas leakage. When temperature exceeds the threshold, the LED turns ON. When gas is detected, the buzzer alerts the user.

## Features
- Temperature Monitoring
- Gas Leakage Detection
- Visual Alert (LED)
- Audio Alert (Buzzer)

## Tools Used
- Arduino UNO
- Tinkercad
- GitHub
